# Google Antigravity

## Configuration

1. In Antigravity, open the **MCP Servers** panel.
2. Click **Add Server Configuration**.
3. Set the endpoint:
   - **URL:** `https://api.harness.zuey.me/mcp`
   - **Headers:** `Authorization: Bearer <YOUR_DASHBOARD_API_KEY>`
4. Confirm connectivity and ensure tools are active in your workspace sessions.
