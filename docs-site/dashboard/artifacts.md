# Workspace Artifacts

Artifacts are output files generated by workspace tasks that survive container termination.

## Limits & Retention

- **Max Artifact Size:** 16 MB per single file (configurable via `MAX_ARTIFACT_BYTES`).
- **Principal Quota:** 128 MB total storage across all stored artifacts.
- **Retention Window:** Default 24 hours (`ARTIFACT_RETENTION_SECONDS=86400`).

Operators can browse and download generated artifacts directly from the dashboard, and MCP agents can snapshot, list, read in bounded chunks, and restore artifacts into active workspaces for cross-session handoffs.

## The Artifacts page

`/dashboard/artifacts` lists your retained artifacts a page at a time (the page position
is kept in the address, so **Next page** survives a reload). Each row shows the logical name,
size, SHA-256 digest and expiry, with a **Download** link served from the
dashboard's own API path.

- **Create snapshot** retains one file from a workspace: enter the workspace ID, the path
  inside the workspace, a logical name, and a retention between 60 seconds and 30 days.
- **Delete** asks for confirmation and sends the artifact's generation, so an artifact
  that changed since the page loaded is refused instead of deleted.

Restoring an artifact into a workspace is available to MCP agents only for now. A
workspace's own **Artifacts** section in the cockpit lists that workspace's artifacts
read-only, with the same download links.
