# Workspace Artifacts

<div class="md-twin-hint">
  <strong>AI Crawler / Raw View:</strong> Fetch this page as raw Markdown at <code>/dashboard/artifacts.md</code>.
</div>

Artifacts are output files generated by workspace tasks that survive container termination.

## Limits & Retention

- **Max Artifact Size:** 16 MB per single file (configurable via `MAX_ARTIFACT_BYTES`).
- **Principal Quota:** 128 MB total storage across all stored artifacts.
- **Retention Window:** Default 24 hours (`ARTIFACT_RETENTION_SECONDS=86400`).

Operators can browse and download generated artifacts directly from the dashboard, and MCP agents can snapshot, list, read in bounded chunks, and restore artifacts into active workspaces for cross-session handoffs.
