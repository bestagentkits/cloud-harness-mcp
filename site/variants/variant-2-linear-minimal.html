Unlike running agent commands directly on your workstation or in insecure multi-tenant clusters, Cloud Harness enforces a strict boundary between the control plane and ephemeral non-root executors.

Architecture Diagram

Boundary Separation & Data Isolation

Internet-facing request handling is kept away from Docker authority, and repository credentials never enter long-lived executors.

Core Capabilities

Engineered for Autonomous Reliability

A complete suite of primitives allowing your agents to browse, refactor, test, and commit code safely.

Structural AST Intelligence

Execute syntax-aware pattern searches and atomic rewrites across TypeScript, Python, Go, and Rust without broken regex edits.

Persistent PTY & Shells

Run long-running builds, live test watchers, or REPL sessions with full signal handling, resize support, and cursor navigation.

Credential-Isolated Git

Fetch and push using short-lived GitHub App tokens transferred over stdin to an ephemeral helper. Push keys never touch executor disks.

Isolated Worktrees

Spawn instant Git worktree branches for subagent investigations, preventing concurrent edit collisions or dirty git checkouts.

DAG Task Graphs

Dispatch multi-stage task graphs with explicit dependency barriers, stage rollbacks, and structured artifact collections.

Time-To-Live Hard Stops

Every workspace has strict execution deadlines. Abandoned sessions are automatically reclaimed and removed from Docker memory.

STEP 01

Open & Isolate

Agent calls workspace_open with a target repo. The runner clones via an ephemeral helper and boots a fresh non-root container in seconds.

STEP 02

Explore & Execute

Agent inspects files, runs tests, triggers AST refactors, or builds Docker images inside the constrained container boundaries.

STEP 03

Push & Purge

Agent stages clean commits. The broker securely pushes via short-lived GitHub App tokens, and workspace_close wipes all state.
