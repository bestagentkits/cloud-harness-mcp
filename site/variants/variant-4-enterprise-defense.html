Six Hardened Security Guarantees

Every build and release is tested against strict boundary isolation invariants.

🔒 Strict Non-Root Execution

Executors run under unprivileged UID 1000. Privileged mode, capabilities, and kernel namespace breakouts are strictly blocked.

🛡️ Stdin Secret Streaming

GitHub App private keys reside exclusively in the runner control memory. Temporary tokens stream over stdin and vanish immediately.

⏱️ Time-To-Live Auto-Eviction

Abandoned workspaces are automatically cleaned up when the execution timer expires, eliminating orphaned processes.

🌐 Network Isolation Default

Default network mode is none. Outbound exfiltration to unverified external endpoints is prevented by the container engine.

🗄️ Cryptographic State DB

SQLite metadata state tracks active workspace IDs, TTL bounds, and principal authorizations with local encryption.

📦 0 Bytes Residual Footprint

Calling workspace_close deletes container volumes and transient checkouts immediately, leaving zero residual disk footprint.
