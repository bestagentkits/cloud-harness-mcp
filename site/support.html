Install the skill, connect a trusted client, and report problems safely.

Install the skill

Install the portable operating guidance with:

npx skills add bestagentkits/cloud-harness-mcp --skill cloudharness

This installs guidance only. It does not install an access token or register an MCP connection.

Before reporting a connection problem

The hosted service has two separate, non-interchangeable lanes. Identify which one your client uses first.

  • Managed OAuth at https://harness.zuey.me/mcp: Cloudflare Access is the OAuth authorization server, and GitHub or Google sign you in to Access. Discovery, client registration, browser login, redirect-URI, refresh, and revocation failures belong to the Access configuration, not to an API key.
  • Static API key at https://api.harness.zuey.me/mcp: send a dashboard-managed key as Authorization: Bearer. A 401 means the key is expired, revoked, or mistyped; a 400 means the Authorization: Bearer header is missing or malformed. A key sent to the OAuth URL fails at Cloudflare Access instead.
  1. Confirm you are an authorized owner of the hosted instance.
  2. Confirm the endpoint matches your lane and is reachable. Keep any API key only in your local client's private credential store.
  3. Confirm the client supports Streamable HTTP MCP and the lane's authentication method.
  4. Capture the bounded error code, client version, operation name, and sanitized reproduction steps. Never include an API key, OAuth token, authorization code, or Cf-Access-Jwt-Assertion value.

How the OAuth lane works is explained in the security model.

Public support

Search or open a GitHub Issue for installation, documentation, compatibility, or reproducible software defects. Include expected and actual behavior and the smallest safe reproduction. Never post tokens, private URLs, source code, command output containing secrets, personal data, or infrastructure credentials.

Security reports

Do not file suspected vulnerabilities in a public issue. Use GitHub Security Advisories so the report and follow-up remain private.

Marketplace and hosted connector status

The repository packages a self-contained skill for skills-compatible clients, Claude Code plugins, and OpenAI plugins. The hosted MCP service remains a private, owner-operated deployment for one trusted security domain, not a hostile multi-tenant service. It already exposes Cloudflare Access Managed OAuth for owner-authorized ChatGPT and hosted Claude connections, alongside the separate static API-key lane. Working OAuth is not a marketplace listing: public connector distribution still requires marketplace review, and plugin installation alone does not change that boundary.
