// Hardened Topology

System Architecture

One credential-free ingress, a trusted control plane that owns every secret and the Docker socket, and disposable execution containers that run repository code, managed agents, and Git transfers on separate rails.

Plane 01 // Edge & Ingress

Credential-Free Ingress

Cloudflare Access Managed OAuth is the authorization server at the perimeter, and the API verifies only the signed assertion Access forwards. Dashboard API keys use a separate lane. The ingress proxy holds no secrets and never joins the control network. How the OAuth lane works.

  • ✓ Managed OAuth via Cloudflare Access (GitHub/Google sign-in)
  • ✓ Separate API-key lane for static-header clients
  • ✓ The only host-published service, on loopback
Plane 02 // Trusted Control

API, Runner & Gateways

The API speaks MCP, serves the dashboard, fronts your downstream MCP servers, and delivers signed event webhooks. The runner alone owns the Docker socket, encrypted state, and GitHub App credentials, and feeds a separate model gateway that keeps provider keys out of every container.

  • ✓ Idempotent workspace and agent lifecycle
  • ✓ Write-only secrets in an AES-GCM keyring
  • ✓ Per-agent leases with pre-reserved budgets
Plane 03 // Execution Plane

Disposable Containers

Repository code runs in a non-root executor with a read-only root filesystem and resource caps. Dependency egress is the shipped default and network-none is the per-workspace or instance-wide opt-out. Managed agents and Git transfers each get their own short-lived container.

  • ✓ Non-root UID, no Docker socket, no control-plane credentials
  • ✓ Agent containers: no repository mounts, no secrets
  • ✓ Purged on workspace_close or TTL expiry

// Zero-Trust Security Guarantees

Hardened Single-Owner Invariants

Designed intentionally for one trusted operator or team. Arbitrary execution capability inside shared-kernel executors with strict boundary separation.

🔒 No Docker Host Socket Mounting

The API and Ingress proxy never receive Docker socket mounts or host volume binds. Docker daemon control remains strictly localized to the trusted Runner daemon.

🔑 Runner-Only GitHub App Credentials

GitHub App private keys stay inside the runner. Installation tokens are short-lived and piped over stdin to an ephemeral git helper.

🛡️ Non-Root Docker Sandboxes

Executors run as non-root UID 10001 with read-only root filesystems and memory/CPU caps. Dependency egress is the shipped default and is never a silent downgrade; choose network-none per workspace or instance-wide for full isolation.

⏱️ Automatic TTL Cleanup & Zero Residuals

Workspaces are destroyed immediately upon workspace_close or when TTL expires, leaving zero leftover state, containers, or leaked temp files.
