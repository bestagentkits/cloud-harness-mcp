CloudHarness MCP · Architecture & Design Brief

Secrets & Credentials Management: Description, MCP Discovery & Zero-Leakage Injection

Đặc tả kiến trúc hoàn chỉnh cho tính năng quản lý Secret có Description, công cụ khám phá MCP secrets_list (hoàn toàn không lộ value), bộ lọc Aho-Corasick Ingest-time Redaction Engine tự động che dấu secret trong output command, và cơ chế khôi phục workspace an toàn.

1. Bounded Delivery Contract (Khung Giao Ước)

Best-of-5 + Kongming Verified

Outcome (Mục tiêu sau cùng)

Operator quản lý Secrets theo Environment kèm trường Description (mô tả nền tảng, tài khoản); AI Agent qua MCP có công cụ secrets_list để khám phá danh sách biến môi trường sẵn có (tên + mô tả, không value); khi chạy lệnh (exec_run, tasks_run, shell_io), secret được inject an toàn vào container và tự động kiểm duyệt (redact) [REDACTED_SECRET: NAME] trên toàn bộ stdout/stderr để không bao giờ lộ vào transcript cuộc hội thoại.

Constraints (Ràng buộc an toàn)

  • Physical No-Decrypt on Discovery: secrets_list chỉ truy vấn bảng secret_references, tuyệt đối không gọi environmentValues() hay Keyring.
  • Ingest-Time Redaction: Khử secret tại thời điểm nhận byte stream trong Runner trước khi ghi vào buffer, đảm bảo toàn vẹn không gian cursor (byte-offset pagination).
  • Strict Description Limit: description là plain text non-secret, tối đa 500 ký tự, không bao giờ được đưa vào container env.
  • Metadata Migration v2 -> v3: Thêm cột description TEXT có kiểm soát downgrade/idempotency.

Non-goals (Phạm vi từ chối)

  • Không hỗ trợ giải mã hay hiển thị giá trị secret trong bất kỳ công cụ MCP nào.
  • Không làm full-text search engine phức tạp (dùng case-insensitive substring search cho query).
  • Không redacting input do agent tự gõ (agent chịu trách nhiệm về câu lệnh nó viết).

Acceptance Criteria (Tiêu chí nghiệm thu)

  • AC1: Database schema migration v2 -> v3 thêm cột description vào secret_references; SecretView và API CRUD cập nhật đầy đủ.
  • AC2: Thêm tool MCP secrets_list: trả về danh sách {name, description, environmentId, version, updatedAt}, hỗ trợ filter query.
  • AC3: Bulk .env Import tự động trích xuất các comment # ... liền kề phía trên làm description của secret.
  • AC4: Ingest-Time Output Redaction: Lệnh echo $STRIPE_KEY trả về [REDACTED_SECRET: STRIPE_KEY] trên cả text và structuredContent của tool response.
  • AC5: Persist environment_id vào WorkspaceRecord, đảm bảo recovery khôi phục container đầy đủ secret.

4. Chi Tiết Kỹ Thuật (Technical Specifications)

Database, Tooling & Engine

1. SQLite Migration (v2 -> v3)

  • File: apps/runner/src/metadata-schema.ts
  • Nâng version ladder lên 3.
  • DDL: ALTER TABLE secret_references ADD COLUMN description TEXT;
  • Cập nhật metadata-records.ts: SecretRow.description, SecretView.description: string | null.
  • Thêm endpoint secret_update cho phép sửa description mà không cần nhập lại secret value.

2. MCP Tool: secrets_list

  • File: packages/contracts/src/tool-schemas.ts
  • Schema: { ...workspace, environmentId?, query?, cursor?, limit? }.
  • Annotations: readOnlyHint: true, idempotentHint: true.
  • Output Schema: { secrets: [{ name, description, environmentId, version, updatedAt }] }.
  • Đảm bảo tuyệt đối không có trường value trong output contract.

3. Ingest-Time Output Redaction

  • File: apps/runner/src/operation-manager.ts & workspace-service.ts.
  • Xây dựng Aho-Corasick automaton từ danh sách (name, value) snapshot lúc mở workspace.
  • Khử trực tiếp trên stream chunks của stdout/stderr trước khi tính toán byte offset của cursor.
  • Sanitize string trên runWorker result và các điểm dựng HarnessError.message.

5. Kế Hoạch Triển Khai Hoàn Chỉnh (3-Phase Plan)

Phase 1: Persistence & Policy

  • Tạo secret-policy.ts (chặn biến cấm).
  • Migration SQLite v2 -> v3 (thêm description).
  • Thêm environment_id vào WorkspaceRecord (sửa lỗi recovery).
  • Thêm secret_update API & cập nhật CRUD.

Phase 2: MCP Tool & Redaction

  • Đăng ký tool MCP secrets_list trong contracts.
  • Cài đặt Aho-Corasick Ingest-time Redaction Engine trong Runner.
  • Tích hợp redaction vào exec_run, tasks_status, shell_io, sessions_io, và error messages.
  • Viết test kiểm thử khử chuỗi và bảo toàn cursor.

Phase 3: Dashboard UI & Bulk .env

  • Cập nhật Secret Table hiển thị Description và form Edit Description.
  • Cải tiến Bulk .env Parser tự động lấy comment làm Description.
  • Tạo Export .env.example manifest.
  • Chạy kiểm thử UI contract và visual test.
